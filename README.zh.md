# dsh-reasoning-picker（推理等级挑选器）

给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 输入框加一个小按钮，回答发消息前的一个问题：**这条草稿到底需要多强的模型？**

点一下发送按钮旁边的 📊 按钮：插件读取你的草稿（以及最近几条对话），让一个轻量模型判断难度，然后给出推荐 —— 用 **Flash** 还是 **Pro**、对应哪个推理等级、一句超短理由。**它不会自动改任何设置，也不会替你发消息**；只有你点「应用」，推荐才会写进当前会话的模型选择。

目的是别让「重命名一个变量」也跑在 `Pro · High` 上，而真正难的任务又不至于只拿到 Flash。

## 安装

```sh
dsh plugin add dsh-reasoning-picker
```

装完重启 DSH（或刷新页面）让浏览器端加载。按钮出现在输入框右侧的工具栏里。

## 工作方式

| 步骤 | 发生什么 |
| --- | --- |
| 1 | 你写好草稿，点 📊 |
| 2 | 宿主读取草稿和本会话最近几条消息 |
| 3 | 轻量模型从「按你实际可用模型生成的阶梯」里挑最省的一档 |
| 4 | 浮窗显示 `Flash · Off` / `Pro · Low` … 以及一行理由 |
| 5 | 你点「应用」，此时才把 provider/model/effort 写进当前会话 |

- **绝不自动发消息**：草稿原样留在输入框，发送键仍然由你按。
- **绝不自动切换**：只做评估时，当前等级不变。
- **用你自己的模型列表**：阶梯由 `sessionController.modelCatalog()` 返回的真实模型生成，不写死档位。
- 评估模型跑在该模型支持的最低档，评估本身几乎不花钱。

## 配置

零配置即可用。可选配置项：

| 键 | 默认 | 含义 |
| --- | --- | --- |
| `flashModel` / `flashProvider` | 自动识别 | 强制指定「便宜档」模型 |
| `proModel` / `proProvider` | 自动识别 | 强制指定「强档」模型 |
| `maxRecentMessages` | `6` | 传给评估模型的最近消息条数 |
| `maxRecentChars` | `1400` | 最近上下文的字符预算 |
| `maxDraftChars` | `4000` | 草稿截断长度 |
| `timeoutMs` | `15000` | 评估超时 |

## 隐私与安全

- 两条 HTTP 路由只监听回环地址，并拒绝转发头 / 跨源请求。
- 草稿与最近上下文经 DSH 自带的 `llm` 服务发给你已配置的模型，没有第三方端点。
- 无遥测。
